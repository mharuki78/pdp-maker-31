# 공통 이미지와 다운로드

편집기 상단 **전체 다운로드**에서 설정한다.

- 첫 이미지 → 본문 순서 → 마지막 이미지를 같은 폭으로 이어 통합 PNG 한 장을 만든다. 첫·마지막 이미지는 선택 사항이며 원본 비율을 유지한다.
- PNG·JPG·WebP를 파일당 10MB, 3,200만 화소까지 등록한다. 투명 영역은 통합 이미지에서 흰색으로 표시된다. ZIP의 공통 이미지는 원본 파일 형식을 유지한다.
- 공통 이미지는 이 PC·브라우저의 IndexedDB(`baegot-pdp-export-settings`)에 보관한다. 새 작업에도 적용하며 교체·제외할 수 있다. 서버나 다른 PC와 자동 공유하지 않는다. 작업 JSON 백업과는 별도 설정이다.
- 상품 원본 사진(히어로에 교체한 상품 참조가 있으면 해당 사진)에서 **상품만 추출해 두 규격 만들기**를 누르면 현재 연결된 AI 모델로 흰 배경·문구 없는 상품컷 한 장을 만든다. 상세페이지의 카피·연출·인물 참조·번역 지시를 사용하지 않는 전용 프롬프트로 상품 형태·색상·구성품을 유지하고 배경·광고 문구·소품을 제거한다. 한 요청만 전송하며 실패·응답 미확인 시 자동 재시도하지 않는다. 초기 패널 열기나 구도 변경은 유료 요청을 만들지 않는다. 기존 공급자 API 연결과 비용 안내를 사용한다.
- 상품컷 한 장으로 네이버 750×750, 쿠팡 1000×1000 JPG를 각각 렌더링한다. 바깥 여백을 줄여 긴 변이 약 94%를 차지하도록 배치하고, 가장자리와 연결된 거의 흰 배경을 #FFFFFF로 정리한다. 확대·좌우·상하를 조절할 수 있다. 두 규격 생성·구도 조절·다운로드에는 AI를 재호출하지 않는다. 원본 사진은 바꾸지 않는다.
- 추출한 상품컷은 원본 사진의 SHA-256 키로 같은 PC·브라우저의 IndexedDB에 최근 6장까지 보관한다. 다음에 같은 사진을 열면 재사용하며, 공통 첫·마지막 이미지와 별도 레코드를 사용한다. 전용 사진 선택·구도는 현재 편집 화면에서 유지한다. 상품컷을 다시 추출하려면 추가 비용 안내를 펼친 뒤 버튼을 직접 눌러야 한다. 상품이 여러 종류인 자료는 별도의 상품 사진을 선택하면 더 정확하다. 추출 전 ZIP에는 상세페이지 이미지만 포함됨을 화면에 안내한다.
- 두 규격은 같은 상품 구도에서 각각 렌더링한다. 썸네일 구도를 바꾸면 이전 ZIP 링크는 비우며, 본문 PNG와 ZIP의 본문 이미지는 기존 레이어 렌더러로 별도 준비한다.
- 개별 이미지 ZIP에는 등록한 첫·마지막 이미지, 생성된 본문 순서, 두 썸네일이 포함된다. 통합 PNG는 모든 본문 이미지가 있을 때만 허용한다. ZIP에서는 미생성 본문이 제외되며 화면과 완료 안내에 표시한다.
- 통합 파일은 최대 폭 1080px, 높이 30,000px, 1,600만 화소 안에서 브라우저 저장 한도에 맞춰 전체 폭을 조절한다. 폭이 320px 미만으로 줄어야 하는 극단적으로 긴 구성은 개별 ZIP을 안내한다.
- 본문 내보내기는 기존 편집기의 레이어 렌더러를 사용한다. 이미지를 한 장씩 해독하고 임시 캔버스를 해제해 메모리 사용을 제한한다. 준비된 PNG·ZIP은 설정을 바꾸기 전까지 저장 링크로 다시 받을 수 있다.

기존 사용자의 업무 자료를 바꾸거나 전체 이미지를 다시 생성하지 않는다. 기능 검수는 별도 로컬 작업과 자체 샘플 파일로 진행한다.
